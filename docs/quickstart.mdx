---
title: "Quick Start"
description: "Start running your first test in less than 5 minutes."
---

<Steps>
  <Step title="Prerequisites">
    Before you begin, you need:
    - **Java 17** or higher
    - **Gradle 7** or higher
    - **Node.js** (for running the test runner, can be downloaded automatically by using downloadNode setting)
    - **A Paper/Spigot plugin project**
  </Step>

  <Step title="Installation">
    Add Plugwright to your `build.gradle.kts` file:

    ```kotlin
    plugins {
        id("io.github.drownek.plugwright") version "2.0.2"
    }

    plugwright {
        minecraftVersion.set("1.19.4")
        testsDir.set(file("src/test/e2e"))
        acceptEula.set(true)

        // Download some dependencies your plugin might need
        downloadPlugins {
            url("https://url.to/plugin1.jar")
            url("https://url.to/plugin2.jar")
            // ... etc
        }

        // If true, always downloads and uses an isolated Node.js version, ignoring the system Node.
        // downloadNode.set(true)
    }
    ```
  </Step>

  <Step title="Initialization">
    Run the init command to set up the default configuration and an example test in your project:

    ```bash
    ./gradlew plugwrightInit
    ```
  </Step>

  <Step title="Your First Test">
    Run your tests:
    ```bash
    ./gradlew plugwrightTest
    ```
  </Step>
</Steps>
